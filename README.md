# VPBus

**Mô tả ngắn gọn:**  
Ứng dụng *VPBus* là một dự án được phát triển bằng *Android Java* nhằm hỗ trợ người dùng tìm xe bus và tra cứu tuyến,trạm xe bus trên địa bàn tỉnh Vĩnh Phúc (cũ).

---

## Tính năng chính

-  *Tìm tuyến xe buýt nhanh chóng* 
-  *Hiển thị bản đồ với lộ trình chi tiết* 
-  *Tra cứu tuyến, trạm bus*
---

## Kiến trúc & Công nghệ

- **Ngôn ngữ:** Java 
- **Framework:** Android SDK 
- **Cơ sở dữ liệu:** SQLite & Room
- **Công cụ hỗ trợ:** Android Studio 
- **Thư viện chính:**
    - `Room`, `GraphHopper`, `OpenStreetMap`, ...
